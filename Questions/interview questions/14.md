What is the difference between 'pass by value' and 'pass by referance' ?
In javascript, whenever a function is called, the arguments can be passed in two ways, either pass by value or pass by referance

-> Primitive datatypes such as string, number, boolean, null and undefined are passed by value
-> Non - primitive datatypes such as object, arrays or functions are passed by referance

In pass by value, parameters passed as an arguments creater their own copy. So any changes made inside the function are made to the copied so it will not affect the original value
In pass by refrance, parameters passed as an agruments does not create thier own copy. So any changes made insdie the function will affect the original value.
