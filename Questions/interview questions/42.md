What is the main difference btween local storage and session storage ?

-> Local storage and session storage are two ways of storing data using key value pairs in we browsers

-> LocalStorage is the same as SessionStorage but it presists the data even when the browser is closeed and reopenedd and on reload (i.e it has no expiration time) whereass in sessionStorage data gets cleared when the page session ends

-> Both provides same meathods
setItem(key, vlaue) - stores key/value pairs
getItem(key) - get the value by key
removeItem(key) - removes the key with its value
clear() - delete everything
key(index) - get the key on a given position
length - the number of stored items
