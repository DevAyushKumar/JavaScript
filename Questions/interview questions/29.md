What is the difference between typescript and javascript ?

-> Typescript is the superset of javascript and has all the object oriented features
-> Typescript is better suited for large scale applications where as javscript is suited for small scale applications
-> Typescript points out the compilation errors at the time of development. Because of this, getting runtime error is less likely
-> functions have optional paramenters in typescript whereas in javscript does not have it
-> Typescript takes longer time to compile code
