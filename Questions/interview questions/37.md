differences between promise.all, allSetteled, any race ?

-> Promise.all:
Will wait for all the promises to resolve or any one of the promise reject

-> Promise.allSettled:
will wait for all the promises to settle (wither fulfilled or rejected)

-> Promise.any:
Will return if any one of the promise fulfills or rejects when all the promises are rejected

-> Promise.race:
Will return as soon as when any of the promsie is settled
