Possible followup questions on session storage: 
1. I created a sessionstorage and closed the browser and reopened it and restored tab. Will session storage data persists ?
-> No session storage data does not persists on browser close and reopen

2. Can i access session storage data in another tab of same browser ?
-> No we cannot access session storage data of one tab in another tab

3. I reloaded the page after creating session storage. Will it persists ?
-> Yes session storage data persists on page reload 

4. If I open multiple tabs with same url how session storag behaves ?
-> we cannot access storage data in multiple tabs even if its same url 

5. If i open multiple windows with same url how session storage behaves ?
-> We cannot access a session storage data in multiple windows even if its the same url 

6. Wheen session storage data will be removed ?
-> Once tab closes or session ends session storage data will be removed 

7. Is session storage synchronous or asynchronous ?
-> Session stoage is synchoronous. If i perform operations on session storage, it blocks the execution of other javscript code until the current operation is completed

8. I want asynchoronous operations and large data sets to be stored then what you will suggest ?
-> I can go with IndexdDbb where asynchoronous operations are supported and we can work with large data sets

9. What is the max storage limit of session storage ?
-> We can store max of 5mb

10. I will try to store lets say an image of size more than 5mb in localstorage then what will happen ?
-> It will throw QuotaExceededException if it exceeds the limit
