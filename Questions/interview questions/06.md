What is differenc between let, var and const ?
-> scope :
Variables declared with var are function scoped. (available throught out the function where its declared) or gloabal scoped (if defined outside the function)
Variables declared with let and const are block scoped

-> Reassignment :
var and lt can be reassigned
const cannot be reassigned

-> Hoisting :
Var gets hoisted and initialized with undefined
let and const - gets hoisted to the top of the scope but does not get assigned any value (temporal dead zone)
