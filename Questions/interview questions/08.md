What are limitations of arrow functions in javascript ?
Arrow functions are introduced in ES6. They are simple abd shorter way to write functions in javascript 
1. Arrow functions cannot be accessed before initialization
2. Arrow functions does not have access to arguments object
3. Arrow functions does not have access in arguments object 
4. Arrow functions does not have their own this. Instead, they inherit this from the surrounding code at the time the function is defined
5. Arror functions cannot be used as constructors. Using then with the new kyword to create instances throws a typeError
